Interval Ride

YouTube를 보는 동안 화면 위에 떠 있는 30분 인터벌 타이머

사용 방법

  1. 타이머 띄우기를 누르면 타이머가 작은 창으로 분리됩니다. 5초 준비 후 워밍업이 시작됩니다.
  2. 작은 창을 손가락으로 끌어 화면 위쪽에 놓습니다.
  3. 홈 화면으로 나가 YouTube 앱에서 원하는 영상을 봅니다. 타이머는 위에 그대로 떠 있습니다.
  4. 작은 창을 한 번 누르면 일시정지·재생 버튼이 나옵니다. 화면 옆으로 밀면 잠시 숨겨 둘 수 있습니다.

구간이 바뀌기 3초 전부터 1초마다 짧은 '삑' 소리와 함께 화면이 깜빡이고, 바뀌는 순간 긴 '삐-' 소리가 납니다. SPRINT가 시작될 때는 두 음으로 더 높게 울립니다. 타이머 소리는 YouTube 소리와 섞여서 나도록 설정되어 있으며, 아이폰이 무음 모드이면 들리지 않습니다. 그래도 YouTube가 멈추면 소리를 끄고 다시 띄워 주세요.
