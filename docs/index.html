Interval Ride

YouTube를 보는 동안 화면 위에 떠 있는 실내자전거 인터벌 타이머

지금은 홈 화면 앱 모드로 열려 있습니다. 이 모드에서는 아이폰이 작은 창(PiP)을 막습니다. Safari에서 열어 주세요.

Safari에서 열기

홈 화면 아이콘을 다시 만들 때는 공유 → 홈 화면에 추가 화면에서 웹 앱으로 열기를 끄면, 아이콘이 Safari로 열립니다.

사용 방법

  1. 타이머 띄우기를 누르면 타이머가 작은 창으로 분리됩니다. 5초 준비 후 첫 구간이 시작됩니다.
  2. 작은 창을 손가락으로 끌어 화면 위쪽에 놓습니다.
  3. 홈 화면으로 나가 YouTube 앱에서 원하는 영상을 봅니다.
  4. 작은 창을 한 번 누르면 일시정지·재생 버튼이 나옵니다.

구간이 바뀌기 3초 전부터 화면이 깜빡이고, 바뀌는 순간 2초간 색이 강조됩니다.
