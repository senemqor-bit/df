# Interval Ride

실내자전거용 30분 인터벌 타이머입니다.
[30분 실내자전거 운동 영상](https://youtu.be/xEhPT6ydXRY)의 화면 타이머를 같은 구간·같은 위치·같은 색으로 옮겼습니다. 다른 YouTube 영상을 보면서도 그 영상과 똑같이 운동할 수 있습니다.

원본 영상의 10초 간격 미리보기 화면에서 타이머 숫자를 읽어 정리했습니다.

## 사용 방법 0: 아이폰에서 YouTube 앱 위에 띄우기

아이폰은 다른 앱 위에 화면을 겹쳐 그리는 것을 허용하지 않습니다. 대신 영상의 작은 창(PiP)은 YouTube 앱 위에도 떠 있을 수 있어서, 타이머를 30분짜리 영상(`mobile/interval-ride-pip.mp4`, 소리 없음)으로 만들어 작은 창으로 띄웁니다.

1. `mobile/index.html` 페이지에서 **타이머 띄우기**를 누릅니다. 페이지 없이 mp4 파일을 Safari에서 재생하고 PiP 버튼을 눌러도 됩니다.
2. 작은 창을 화면 위쪽으로 끌어 둡니다.
3. YouTube 앱에서 원하는 영상을 봅니다. 작은 창을 누르면 일시정지·재생할 수 있습니다.

구간이 바뀌기 3초 전부터 화면이 깜빡이고, 바뀐 직후 2초간 색이 강조됩니다. 아이폰은 한 번에 한 앱의 소리만 재생해서, 타이머에 소리를 넣으면 YouTube가 멈추므로 소리는 넣지 않았습니다.

### 타이머 설정

페이지 아래 **타이머 설정**에서 구성을 바꿀 수 있습니다.

- 간단 설정: 워밍업·쿨다운(분), 스프린트·회복 1회 길이(초), 전체 운동 시간(분)을 넣으면 스프린트 횟수를 계산해 구간을 만듭니다. 남는 시간은 쿨다운에 더합니다.
- 구간 상세 편집: 구간별 종류와 길이를 고치고, 순서를 바꾸고, 추가·삭제할 수 있습니다.
- **저장하고 타이머 만들기**를 누르면 휴대폰 안에서 타이머 영상을 새로 만듭니다(iOS 16.4 이상).
- **기본값 설정**을 누르면 원본 영상 구성(30분, 15구간)으로 돌아갑니다. 기본 구성은 미리 만든 `mobile/interval-ride-pip.mp4`를 씁니다.

기본 영상은 `mobile/render_pip.py`로 다시 만들 수 있습니다.

## 사용 방법 1: YouTube 영상 위에 띄우기 (PC, 권장)

Chrome, Edge, 네이버 웨일에서 쓰는 확장 프로그램입니다. 설치해 두면 YouTube에서 어떤 영상을 열어도 영상 왼쪽 위, 원본 영상과 같은 자리에 타이머가 나타납니다. 전체화면에서도 그대로 보입니다.

### 설치 (처음 한 번)

1. 이 저장소를 내려받습니다. GitHub의 **Code → Download ZIP** 후 압축을 풉니다.
2. 브라우저 주소창에 `chrome://extensions` 를 입력합니다. (Edge는 `edge://extensions`, 웨일은 `whale://extensions`)
3. 오른쪽 위 **개발자 모드**를 켭니다.
4. **압축해제된 확장 프로그램을 로드합니다**를 누르고 `extension` 폴더를 선택합니다.

### 사용

- YouTube 영상을 열면 왼쪽 위에 `05:00 WARM UP` 타이머가 보입니다.
- **원(시계)을 누르면 시작**, 한 번 더 누르면 일시정지합니다.
- 타이머에 마우스를 올리면 버튼이 나타납니다: 이전 구간 / 시작·정지 / 다음 구간 / 처음부터 / 소리 / 숨기기
- 구간이 바뀌기 3초 전부터 짧은 알림음, 바뀌는 순간 긴 알림음이 울립니다. SPRINT 시작음은 더 높게 울립니다.
- 숨긴 타이머는 툴바의 확장 아이콘이나 `Alt+Shift+T`로 다시 표시합니다.
- 다른 영상으로 넘어가거나 페이지를 새로고침해도 타이머는 멈추지 않고 이어집니다.

## 사용 방법 2: 단독 타이머 페이지 (PC·태블릿·휴대폰)

`extension/timer.html` 파일을 브라우저로 열면 큰 타이머, 운동 프로필 그래프, 구간 목록이 함께 나옵니다.

- **작은 창으로 띄우기** (Chrome·Edge·웨일 PC): 타이머를 항상 위에 떠 있는 작은 창으로 분리합니다. YouTube 앱, 다른 브라우저 탭, 동영상 플레이어 등 무엇을 보든 화면 위에 남아 있습니다. 창 크기와 위치는 자유롭게 옮길 수 있습니다.
- 태블릿이나 휴대폰을 자전거 앞에 따로 두고 타이머 전용 화면으로 써도 됩니다. 화면이 꺼지지 않도록 설정합니다(지원 브라우저).
- 키보드: `Space` 시작·정지, `←` `→` 구간 이동. 그래프나 목록의 구간을 누르면 그 구간으로 이동합니다.

## 구간 바꾸기

`extension/interval-core.js` 위쪽의 `PROGRAM` 배열만 수정하면 됩니다. 각 줄은 `['종류', 초]` 형식이고, 종류는 `warmup`, `sprint`, `recovery`, `cooldown` 중 하나입니다. 확장 프로그램은 수정 후 `chrome://extensions`에서 새로고침 버튼을 누르면 반영됩니다.

## 파일 구성

```
extension/
  manifest.json      확장 프로그램 설정
  interval-core.js   타이머 엔진과 화면 (구간 구성 포함)
  overlay.css        타이머 디자인 (영상 높이 비율 기준)
  content.js         YouTube 플레이어에 타이머를 붙이는 코드
  background.js      확장 아이콘 / 단축키 처리
  timer.html, timer.js  단독 타이머 페이지
```
